# 2026-07-29 全栈偏前端每日面试题

## 1. JavaScript：私有字段、品牌检查与跨实例访问

- 题型：语言原理 + 场景题
- 难度：中等
- 可能来源或考察方向：[MDN Private properties](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Classes/Private_properties)
- 题目：SDK 用 `#token` 保存连接凭据。`#token` 与 `_token`、闭包变量分别有什么封装差异？为什么类方法可以读取另一实例的 `#token`，而普通对象或子类不能伪造它？`#token in value` 能解决什么校验问题？这种私有字段为何不应直接承担“安全存储密钥”的职责？

## 2. TypeScript：`NoInfer` 与泛型 API 的推断控制

- 题型：TypeScript 类型设计 + 手写
- 难度：较难
- 可能来源或考察方向：[TypeScript Utility Types: NoInfer](https://www.typescriptlang.org/docs/handbook/utility-types.html#noinfertype)
- 题目：实现 `createColorPicker<C extends string>(colors: readonly C[], defaultColor?: NoInfer<C>)`，使默认值必须来自 `colors`，但不能反过来把 `defaultColor` 推断进颜色联合。解释不使用 `NoInfer` 时可能出现的错误推断；它与 `as const`、`satisfies` 各解决什么问题？运行时又该如何处理来自 URL 的非法颜色？

- 可能来源或考察方向：[TC39 Decorators](https://github.com/tc39/proposal-decorators)
- 题目：团队计划把日志能力从 TypeScript 的旧实验性装饰器迁到标准 Decorators。类、方法、字段装饰器接收的 `value`、`context` 分别是什么？多个装饰器的求值和调用顺序如何区分？`addInitializer` 适合解决什么实例初始化问题？为什么不能默认认为它与 `emitDecoratorMetadata` 或 NestJS 依赖注入完全兼容？

## 4. 异步调度：`scheduler.postTask`、优先级与取消

- 题型：浏览器原理 + 性能优化
- 难度：中等
- 可能来源或考察方向：[MDN Scheduler.postTask](https://developer.mozilla.org/docs/Web/API/Scheduler/postTask)
- 题目：搜索页输入后要立刻更新输入框、稍后过滤 5 万条本地数据、后台预取详情。如何用 `scheduler.postTask` 的优先级和 `TaskController` 组织这三类工作？它与 `setTimeout`、微任务、`requestAnimationFrame` 的调度目标有何不同？若不支持该 API，怎样降级并仍避免长任务阻塞交互？

## 5. 浏览器：Shadow DOM 的事件传播与组件事件契约

- 题型：浏览器原理 + 组件设计
- 难度：较难
- 可能来源或考察方向：[MDN Event.composed](https://developer.mozilla.org/docs/Web/API/Event/composed)
- 题目：设计系统的 Web Component 内部按钮触发 `click`，业务页面在宿主元素上做事件委托。解释 Shadow DOM 下的 retargeting、`composedPath()` 与 `composed`；自定义 `CustomEvent` 应怎样设置 `bubbles`/`composed` 才能形成稳定的公共事件 API？哪些内部事件不该跨越 shadow boundary？

## 6. 网络安全：HSTS、CSP 与前端第三方脚本治理

- 题型：网络安全 + 场景设计
- 难度：较难
- 可能来源或考察方向：[MDN Strict-Transport-Security](https://developer.mozilla.org/docs/Web/HTTP/Reference/Headers/Strict-Transport-Security)、[MDN CSP](https://developer.mozilla.org/docs/Web/HTTP/Guides/CSP)
- 题目：运营页需要加载统计、客服和 A/B 测试脚本，同时发生过一次 DOM XSS。请设计 HTTPS、HSTS 与 nonce-based CSP 的上线方案：`strict-dynamic`、nonce、hash 各适合什么脚本来源？Report-Only 如何灰度？为何 HSTS 不能修复用户第一次 HTTP 访问，CSP 又为什么不应替代输入输出编码和服务端鉴权？

## 9. 算法：柱状图中的最大矩形

- 题目：给定非负整数数组 `heights`，返回柱状图能围成的最大矩形面积。请用单调递增栈实现 O(n) 解法，说明压栈不变量、遇到更低柱子时为何可以结算面积，以及首尾哨兵的作用。等高柱子采用 `>=` 或 `>` 弹栈各有什么影响？

- 题目：Kubernetes 滚动发布时，Node BFF 收到 SIGTERM 后仍有 keep-alive 长连接和慢上游请求。请设计关闭流程：何时从负载均衡摘流、何时调用 `server.close()`、怎样处理空闲连接和到期请求、如何把 `AbortSignal` 传给上游 fetch？为什么不能收到 SIGTERM 就立即 `process.exit()`？哪些指标可证明发布没有放大 5xx 或超时？
